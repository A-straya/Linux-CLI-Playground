# Overview

Linux CLI Playground is a browser-based Linux terminal simulator designed to help students practice Linux commands through an interactive environment.

This repository represents the **first public prototype** of the project.

Its main objective is to validate the terminal interface and the command execution engine before implementing more advanced features.

---

# Current Features

- Interactive terminal interface
- Command input system
- Basic command parser
- Command validation
- Terminal output
- Error handling
- Responsive layout

---

# Currently Supported Commands

```text
help
pwd
ls
tree
clear
```

More commands will be introduced in future releases.

---

# Prototype Notice

> [!IMPORTANT]
> This is **Prototype v0.1**.
>
> It is **not** the final version of Linux CLI Playground.

Current limitations:

- No virtual Linux filesystem
- No real Bash interpreter
- Only a few commands are supported
- Linux Labs are not yet integrated
- Missions and progress tracking are not available yet

This repository serves as the foundation for future development.
