# Linux CLI Playground

An interactive Linux terminal simulator built with HTML, CSS, and JavaScript.

The goal of this project is to provide a hands-on environment where students can practice Linux commands without requiring a real Linux installation.

---

## Project Roadmap

- Interactive Linux terminal
- Virtual file system
- Mission-based learning
- Linux Labs integration
- Progress tracking
- Command history
- Autocomplete
- GitHub Pages deployment

---
